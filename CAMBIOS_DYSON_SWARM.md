# Actualización de identidad — Dyson Swarm

Esta versión unifica la identidad del equipo de sistemas CanSat de SAFI bajo el nombre **Dyson Swarm**.

## Cambios principales

- `Dyson Swarm` sustituye a `CanSat` cuando el texto se refiere al **nombre del equipo**.
- `CanSat` se conserva cuando se refiere a la **plataforma**, **misión**, **categoría técnica** o al nombre oficial de una competencia.
- La ruta principal del equipo es `/equipos/dyson_swarm`.
- `/equipos/cansat` se conserva como compatibilidad y redirige a Dyson Swarm.
- El logo oficial del equipo se carga desde `public/images/logos/dyson_swarm.png`.
- El proyecto `Programa CanSat` aparece asociado al equipo Dyson Swarm.
- Inicio, Nosotros, Equipos, Proyectos, Competencias, Únete y Footer ya reflejan la nueva identidad.
- Se añadió una página 404 personalizada y `robots.txt`.
- El workflow de GitHub Pages usa Node 22 y `npm ci`.
